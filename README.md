# Chong Liu academic website

Personal academic portfolio, hosted on GitHub Pages at https://chongliu129.github.io/.

## Pages

- `index.html`: profile, projects, publications, design work and academic background.
- `environmental-novelty.html`, `children-landscapes.html`, `railway-landscapes.html`: research project details.
- `cv.html`: printable academic CV. Use its Print / Save as PDF button.
- `publications.bib`: citation export for the three featured publications.

## Development

This is a buildless static website. Serve the repository root with a static HTTP server. All assets are local and no third-party scripts, analytics, fonts or build dependencies are required. Publish by updating the existing GitHub Pages source branch.

Professional facts are based on the English CV supplied by Chong Liu in October 2026. Research statuses are preserved: current projects are not presented as completed findings.

The visual structure is inspired by the user's reference, SmartScape Design Lab: a wide landscape banner, spacious image-and-text project rows, and publication text alongside journal/book and article previews. Its branding, imagery and research claims are not reused.
